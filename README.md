# ज्ञानवृक्ष

हिंदी में कंप्यूटर की बुनियाद सीखने के लिए एक इंटरैक्टिव वेबसाइट।

लाइव वेबसाइट: https://getnomore.github.io/gyan/

19.5 सेकंड का हिंदी परिचय: https://getnomore.github.io/gyan/short/

सीधा MP4: https://getnomore.github.io/gyan/intro.mp4

6 शाखाओं में 21 विषय, हर विषय का अपना PNG, दिन और रात, सर्दियों का दृश्य, कैमरा ज़ूम, उदाहरण, पढ़ाई की प्रगति, मेमोरी कन्वर्टर, PC असेंबली लैब और क्विज़।

`index.html` को सीधे ब्राउज़र में खोल सकते हैं। CSS, JavaScript और सभी PNG मुख्य HTML के अंदर हैं, इसलिए वेबसाइट को चलने के लिए इंटरनेट या किसी बाहरी लाइब्रेरी की ज़रूरत नहीं है। मूल PNG `assets/topics/` में भी उपलब्ध हैं।

GitHub Pages मुख्य शाखा की जड़ से प्रकाशित होता है।
